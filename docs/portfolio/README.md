# Screenshots (portfólio)

**Automático (HTML demo, sem Tkinter):**

```powershell
cd C:\DEV\Dash\projeto_relatorio
npm init -y
npm install playwright
npx playwright install chromium
node scripts/capture-portfolio-screenshots.mjs
```

**UI real:** rode `python gerar_relatorio.py` com `data/sample_data.xlsx` e capture a janela (Win+Shift+S).

Saída: `screenshots/`
